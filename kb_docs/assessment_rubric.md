# Readiness Assessment Rubric
Synthetic document for demo use only.

Green:
- All required certifications completed or validated.
- Practice score is 80% or higher.
- Focus capacity is sufficient.
- No missing evidence.

Amber:
- One role is close to readiness but has a score between 70% and 79%.
- Required study plan can close the gap before launch.
- Manager approval required.

Red:
- Any required role has a practice score below 70%.
- Any required role lacks responsible AI readiness.
- Workload constraints make readiness unlikely before launch.
- Evidence is missing or not grounded.

The agent must avoid declaring Green readiness when evidence is incomplete.
